# Jelajah Klamono

Sumber website [jelajahklamono.com](https://jelajahklamono.com): jejaring wisata berbasis komunitas dan pustaka pengetahuan Suku Moi di Distrik Klamono, Kabupaten Sorong, Papua Barat Daya. Disusun oleh Tim Ekspedisi Patriot 20 Universitas Brawijaya 2026 bersama warga Klamono Raya.

- Website statis, tanpa proses build di server. GitHub Pages menayangkan isi cabang `main` apa adanya.
- `index.html` dibuat oleh `_alat/bangun.py` (jalankan `python3 _alat/bangun.py` setelah mengubah judul/meta). Skrip ini juga menulis `robots.txt` dan `sitemap.xml`.
- Data yang paling sering diubah: `pengaturan.js` (kontak, pengalaman wisata, titik peta, tim) dan `konten/*.js` (tanaman obat, pengetahuan, kisah & berita).
- `CNAME` menetapkan domain jelajahklamono.com. `googlef400d2f9674b991e.html` adalah file verifikasi Google Search Console; jangan dihapus.
- `google-apps-script/Kode.gs` adalah kode email otomatis untuk Google Sheet (tidak ikut tayang).

Pengetahuan lokal di website ini milik masyarakat adat Moi.
